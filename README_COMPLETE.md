# SOPHENIC Agent Autonome

## Installation
npm install

## Variables environnement
Voir .env.example. Ajouter les clés OAuth/API des connecteurs activés.

## Lancement local
npm run dev
npm run electron

## Déploiement Railway
Configurer les variables d'environnement, installer les dépendances et lancer le script de production défini dans package.json.

## Architecture agent
- Agent Brain
- Planner
- Tool Router
- Memory System
- Execution Engine
- Connecteurs OAuth/API
