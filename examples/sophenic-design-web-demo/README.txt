SITE DE TEST SOPHENIC DESIGN

Dans SOPHENIC Design :
1. Créer un projet > Design Web.
2. Cliquer sur "Importer dossier" et sélectionner ce dossier.
   OU importer le fichier sophenic-design-web-demo.zip fourni à côté.
3. Vérifier que le site s'affiche dans la preview.
4. Demander : "Rends le design de ce site 100x mieux d'après toi, mais garde tout son contenu et ses fonctionnalités."
5. Tester Inspecter puis cliquer sur la hero et demander : "Rends cette section plus premium."
6. Tester Desktop / Tablet / Mobile puis "Exporter site".
